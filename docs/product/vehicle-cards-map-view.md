# Vehicle cards and map viewport

Unpublished local candidate stacked on passenger-search commit `9d115a7`. The existing live release, main branch, gateway DTO, source polling and expiry contracts are unchanged.

Selecting a bus or train opens a nonmodal card immediately: a bottom sheet on mobile, an overlay within the desktop map. Close and Escape return focus; list selections scroll an offscreen desktop card into view. Keyboard Enter and Space activate individual and grouped markers. The displayed source, retrieved time, coordinates and GPS/report quality come directly from the validated location record. Irish Rail observation age and precision remain unknown. Operator, exact service, stops, path, delay and cancellation are explicitly unavailable; no matching by line number or train code is introduced.

Overlapping markers form screen-space connected components using neighbouring grid cells. Each group remains anchored to a real member location, avoiding the centroid collision found by independent review. Group lists preserve access to every vehicle even when positions are identical. Geographic grouping is display-only and asserts no service or trip relationship.

Counters and the vehicle list follow current map bounds and mode, alongside a separate available count. Mayo and Ireland controls change the camera; selecting from the list focuses the reported coordinates. A filtered, unavailable or expired selection closes with an explanation, without claiming cancellation. Refresh never changes the source observation timestamp. Existing thirty-second polling, hidden-tab pause, twelve-second request abort and observation expiry remain intact.

Validation: standalone build and **36 desktop/mobile Playwright checks**, including prior live-data freshness, cancellation, snapshot, error and navigation cases. New tests cover grid boundaries, a ring around a separate central vehicle, viewport/list coherence, scrolled desktop selection, keyboard group selection, focus restoration, source expiry, escaped upstream text and widths320/360/390/430/768/1440. Browser tests use explicitly synthetic offline source fixtures and stub tiles; they are not actual GPS/device validation or a new production verification. Initial keyboard failures were fixed; a mobile test now closes the sheet before using background departure controls. Independent review prompted member anchoring and visibility fixes; its final receipt is recorded with the execution evidence.
